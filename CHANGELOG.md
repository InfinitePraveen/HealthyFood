# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-10-31

### Added
- Initial HealthyFood pilot monorepo.
- NestJS API starter with health, menu, order, and interaction endpoints.
- FastAPI deterministic clinical-rule evaluation service.
- Next.js customer pilot interface.
- PostgreSQL starter schema and Docker Compose development database.
- CI workflows, tests, architecture notes, and launch-readiness checklist.

### Not included
- Production identity/MFA, HIPAA operational controls, licensed interaction content, clinical sign-off, live payments, FHIR/EHR, payer claims, BLE cold-chain integration, or production dispatch.
